# 借地・借家の期間（shakuchi-shakuya）

借地権の長さ・更新・建て直し・一般定期借地権・事業用定期借地権・建物譲渡特約・定期借家の通知と中途解約・1年未満の借家・民法の賃貸借の上限と短期賃貸借などの場面を読んで、その期間（1か月・2か月・3か月・6か月・1年前〜6か月前・1年・2年・3年・5年・10年・20年・30年・50年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（借地の期間／定期の借地・借家／借家と賃貸借のそのほか）も選ぶ。借地・借家のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/shakuchi-shakuya/>

- 中身は e-Gov 法令検索の借地借家法（<https://laws.e-gov.go.jp/law/403AC0000000090>）第3・4・7・8・10・22・23・24・29・35・36・38条と、民法（<https://laws.e-gov.go.jp/law/129AC0000000089>）第600・602・604・622条に書いてある期間だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。地代や家賃の額・更新料・敷金・古い借地法の契約は省いています。公式の情報の代わりではありません。実際の契約は、法務省の案内や専門家に確かめてください。
- 部屋を借りるきまり（chintai-kimari）が扱う借地借家法 第26〜32条（更新しない通知・解約の申入れなど）・民法 第617条とは重ねていません。
- 2段目は、きまりの種類で分けています。
